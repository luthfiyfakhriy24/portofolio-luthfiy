# Muhammad Luthfiy Fakhriy - Personal Portfolio

Website portofolio profesional untuk **Muhammad Luthfiy Fakhriy** — Electrical Engineer yang mendalami sistem Industrial Control, PLC Systems, dan Pemeliharaan Kelistrikan Industri.

## 🛠️ Teknologi yang Digunakan
- **HTML5 Murni** (Semantic & Accessible)
- **CSS3 Modern** (CSS Variables, Flexbox/Grid, Dark & Crimson Red Theme, Fully Responsive)
- **Vanilla JavaScript** (Scrollspy, Dynamic Stats Counter, Interactive Modals, Toast Notification, Email Copier)
- **Zero Dependencies** (Tanpa framework atau library eksternal)

## 📁 Struktur Berkas
```
├── index.html                  # Halaman utama
├── style.css                   # Desain & tata letak responsif
├── script.js                   # Interaktivitas web
└── assets/
    └── images/
        ├── profile.jpg         # Foto profil resmi
        ├── project1-mixer.svg  # Diagram Dual Liquid Mixer PLC
        ├── project2-bottle.svg # Diagram Bottle Filling & Sealing
        └── project3-panel.svg  # Diagram MCC Panel & Instruments
```
